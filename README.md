# CV Dinamic

Estructura base para un CV web dinámico.

## Estructura

- `index.html` — página principal.
- `css/` — estilos globales, componentes y responsive.
- `js/` — lógica de navegación, inicialización y datos del CV.
- `assets/images/` — imágenes de perfil, portfolio y fondos.
- `assets/icons/` — iconos.
- `assets/documents/` — documentos.
- `sections/` — secciones independientes del CV.

El proyecto está preparado para crecer y publicarse posteriormente con GitHub Pages.
