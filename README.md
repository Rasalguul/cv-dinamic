# CV dinámico

Estructura base de un CV web desarrollado con HTML, CSS y JavaScript vanilla.

El proyecto separa estilos, lógica JavaScript, recursos y páginas de cada sección para facilitar futuras fases. `js/cv-data.js` queda reservado para incorporar datos reales del CV posteriormente. No incluye dependencias externas, backend ni contenido definitivo.

La estructura es compatible con la publicación estática mediante GitHub Pages desde la rama `main`.
